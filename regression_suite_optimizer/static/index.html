How it works

  1. Create a project, then upload a BRD/FRS (and optionally user stories, acceptance criteria, or an existing suite).
  2. Run AI Analysis — the app extracts requirements, classifies Functional/Non-Functional items, detects modules and business rules.
  3. Review generated regression test cases, traceability, coverage, risk score, and AI insights.
  4. Export the suite (Excel/PDF/Word/CSV) or a focused report (traceability, coverage, impact, summary).
  5. Re-run analysis after updating documents to see an impact analysis against the previous version.
  6. Use the chat assistant (bottom-right) to ask about specific test cases, business rules, or coverage gaps.

Modes

Set ANTHROPIC_API_KEY and restart the app to enable Claude-powered analysis and chat. Without a key, a deterministic rule-based engine runs fully offline.
